# Assets

Place images, diagrams, and other static files used by the course in this folder.

Suggested naming:

```text
assets/lesson-10-campus-map.png
assets/lesson-23-readme-badge.svg
```

When linking from a lesson, use a relative path:

```markdown
![Campus map](../assets/lesson-10-campus-map.png)
```

If an image is only an example and does not need to exist as a real file, lessons use placeholder paths and explain how students should replace them.
