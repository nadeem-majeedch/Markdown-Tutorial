## Goals

Build a single file `exercises/work/01-notes.md` (create the folder if you need it) that uses only core Markdown: headings, paragraphs, emphasis, and blockquotes.

## Exercises

### 1. Title block

Write an H1 with your name and an H2 `About this file`. One paragraph explaining that this is practice for a Markdown course.

### 2. Paragraph control

Write three sentences.

- First, as **one** paragraph (wrap in the source if you want).
- Then the same three sentences as **three** paragraphs.

Label the two versions with H3 headings.

### 3. Emphasis

In one paragraph, include:

- An italic term on first use
- A bold warning of three words or fewer
- A strikethrough phrase (GFM — optional if your preview lacks it)

### 4. Blockquote

Quote a one-sentence definition of Markdown in your own words, then attribute yourself on the next quoted line.

### 5. Hard breaks

Create a three-line identity block (name, course, date) using backslash breaks, then a blank line and a normal paragraph.

### 6. Debugging

Paste the following broken snippet into a scratch area, then fix it:

```markdown
#My notes
This is** important **and _ also _ broken.
> a quote
that leaks
```

## Self-check

- [ ] The outline shows H1 then H2 then H3s, no skipped levels
- [ ] Blank lines separate blocks
- [ ] No spaces inside `**bold**` markers
- [ ] The quote does not leak into following paragraphs

## Stretch

Explain in two sentences (as a new H2) the difference between source and rendered Markdown, without using the word "pretty."
